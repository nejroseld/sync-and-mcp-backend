# Архитектура сервера obsi-mcp

Сервер хранит зашифрованные файлы для синхронизации, отдельно принимает разрешённые устройством файлы в AI Available и предоставляет доступ к ним через MCP. Контракт HTTP и MCP описан в [API.md](API.md).

`obsi_server/app.py` собирает REST API. `auth.py` управляет токенами и грантами для vault'ов. `storage.py` хранит шифротекст, не имея ключей от vault'ов. `ai_store.py` хранит опубликованные открытым текстом файлы. `changes.py` ведёт очередь правок от MCP; устройство подтверждает их применение. `rag.py` поддерживает FTS и необязательные эмбеддинги. `mcp.py` реализует инструменты для MCP-клиентов. `cli.py` запускает сервер и административные команды. База SQLite и blob'ы находятся в каталоге данных.

Плагин Obsidian живёт в отдельном репозитории и обращается к серверу по HTTP. Правила публикации и ключи шифрования находятся на устройстве; сервер их не получает.
